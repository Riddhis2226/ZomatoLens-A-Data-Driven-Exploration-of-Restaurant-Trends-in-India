# 🧠 Level 3 – Advanced Text, Correlation & Decision Dashboard

Welcome to the **Level 3 Dashboard** of my Data Analysis Internship at **Cognifyz Technologies**. This dashboard tackles complex relationships and text-based insights in restaurant data using advanced analytics and NLP techniques.

---

## ✅ Objective

To perform:

* Text-based sentiment analysis
* Correlation studies (votes vs ratings)
* Service decision insights (price vs delivery/booking)
* NLP-based phrase extraction

---

```
📦 Level 3

```

---

## 📌 Key Features

### 💬 Task 1: Sentiment Analysis on Reviews

* VADER & TextBlob sentiment scoring
* Review length vs rating correlations
* Sentiment labeling (Positive, Neutral, Negative)

### 📊 Task 2: Votes & Rating Correlation

* Scatter plot of votes vs ratings
* Bar chart of average votes by rating text

### 💰 Task 3: Price Range vs Online Services

* Online delivery and table booking stats by price tier
* Normalized visual proportions for clearer decisions

### 🧬 Task 4: spaCy Noun Phrase Extraction

* Top noun chunks from reviews using spaCy NLP pipeline

### 📥 Download Processed Data

* Export sentiment analysis data to CSV for further use
